# Asteria Field map package

These three SVG plates are the stable, reviewable map exports for the Asteria
Field dossier. They are original schematic vector graphics, not orbital
imagery. The local geometry and labels are fictional Red Horizon scenario
details; the parent feature and broad regional context are grounded in the
sources listed in the dossier.

| ID | Stable filename | Image description | Scale / frame | Provenance |
| --- | --- | --- | --- | --- |
| AF-01 | `asteria-field-01-mars-locator.svg` | Mars locator disk with Margaritifer Terra and the fictional Asteria Field marker | Planet-scale schematic; approximate 1,000 km scale bar | Authored vector plate, 2026-09-16; no external base layer |
| AF-02 | `asteria-field-02-regional-context.svg` | Regional scenario context with grid, working units, terrain bands, and field boundary | 327–338°E by 12.5–24°S; approximate 200 km scale bar | Authored vector plate, 2026-09-16; context checked against USGS SIM 3209 envelope |
| AF-03 | `asteria-field-03-local-operations.svg` | Local operations frame with landing ellipse, touchdown zone, science zones, hazards, routes, and comms shoulder | 8 × 6 km frame; 1 km scale bar | Authored vector plate, 2026-09-16; geometry defined by dossier revision AF-0.1 |

The package is intentionally not copied to `content/media/` or
`website/public/`. A human must approve any stable public export separately.
