# Asteria Field map package

These three PNG images are the stable, reviewable map exports for the Asteria
Field dossier. They are generated technical visualizations, not orbital
imagery. The local geometry and labels are fictional Red Horizon scenario
details; the parent feature and broad regional context are grounded in the
sources listed in the dossier.

| ID    | Stable filename                         | Image description                                                                                   | Scale / frame                                        | Provenance                                                                    |
| ----- | --------------------------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------- | ----------------------------------------------------------------------------- |
| AF-01 | `asteria-field-01-mars-locator.png`     | Whole-planet Mars view with Margaritifer Terra and an arrow targeting Asteria Field                 | Planet-scale view; approximate 1,000 km scale bar    | GPT Image generation, 2026-09-16; generated terrain and cartographic overlays |
| AF-02 | `asteria-field-02-regional-context.png` | Regional satellite-style view with field envelope, working units, and centre marker                 | 327–338°E by 12.5–24°S; approximate 200 km scale bar | GPT Image generation, 2026-09-16; generated terrain and cartographic overlays |
| AF-03 | `asteria-field-03-local-operations.png` | Local view with landing ellipse, touchdown zone, science zones, hazards, routes, and comms shoulder | 8 × 6 km frame; 1 km scale bar                       | GPT Image generation, 2026-09-16; generated terrain and cartographic overlays |

The package is not copied to `content/media/` or `website/public/` yet. A
human must approve any stable public export separately.
