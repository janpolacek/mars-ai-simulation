# Image catalog — every project image in one place

Single reference for writers, the reviewer and the image visualizer **before requesting new
art**. The catalog lives at `docs/IMAGES.md` (moved from `.agents/work/image-index.md`,
2026-09-20). Convention (see `.agents/skills/image-index/SKILL.md`):

- **A missing entry means "does not exist — request it".** If a needed image has no row here,
  it is not available to place, reuse or describe.
- Every entry = path + 2–3 sentence description + status. The image visualizer appends one
  entry per generated image after each run and keeps this file the source of truth.
- Hashes are SHA-256, recorded at index time (2026-09-19) and re-verified on the move to
  `docs/IMAGES.md` (2026-09-20); verify with `sha256sum <path>` before relying on a file's identity.
- Statuses: `released` (placed on a public surface), `approved-unplaced` (approved, not
  placed — placement is a fresh decision), `admitted-alternative` (admitted as an
  alternative only), `withheld` (fail-closed, guard-protected or human-gated), `rejected`,
  `legacy-unreferenced`, `candidate` (in the visuals cache, unapproved).
