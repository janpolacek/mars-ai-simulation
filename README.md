# Mars AI Simulation

**Red Horizon** is a fictional, continuously simulated multinational Mars mission.
This repository is the public-site and editorial home for the project, which also
serves as a hands-on AI-harness experiment: collaborating agents develop prose,
continuity, and local ComfyUI media under human approval.

The initial release is intentionally small: a "preparing" page, project identity,
and an honest disclosure of its fictional and AI-assisted nature. The public
story will unfold over time rather than arrive as a completed archive.

## Tracking work

This project uses [Beads](https://github.com/gastownhall/beads). Run `bd prime`
at the start of a work session and `bd ready` to find unblocked work. The local
CLI is installed at `~/.local/bin/bd` on this machine.

## Source imagery

`~/Projects/mars-image-gen` remains the local ComfyUI generation tool. Only
reviewed, stable media is copied here for publication; raw generations,
workflows, models, and run logs do not belong in this repository.
